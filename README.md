# 311-App

## 2025 311 Requests Dashboard

An interactive dashboard for exploring 2025 311 service requests. Filter requests by date range and view the total number of requests, the top 10 responsible agencies, and how requests are distributed across the days of the week.

### Features

- Select a start and end date within 2025
- View the number of requests in the selected period
- Compare the top 10 responsible agencies
- Explore request volume by day of the week

### Run locally

Install the dependencies and start the Streamlit app:

```bash
pip install -r requirements.txt
streamlit run app.py
